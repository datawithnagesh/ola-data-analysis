##Ola Ride Booking Analysis – Data Analyst Project

🎯 Objective
The objective of this project is to analyze Ola ride booking data and identify important business insights related to ride bookings, cancellations, revenue, customer behavior, and driver performance.
The project uses SQL and Power BI to answer real-world business questions, analyze key performance indicators (KPIs), and present the findings through an interactive dashboard.

🛠️ Tools Used
SQL – Data analysis and business queries
Power BI – Interactive dashboard and visualization
Excel – Data source and data preparation

📊 Key Analysis Areas
Total number of bookings
Successful and cancelled bookings
Booking and cancellation analysis
Revenue analysis
Customer and driver insights
Ride performance analysis
Key business KPIs
